# GitHub и GitLab для Harness

Плагин `@workain/dsh-forge` в форке [workain/deepseek-harness](https://github.com/workain/deepseek-harness). Задача GUARD-386.

## Назначение

Именованные подключения GitHub/GitLab, включая собственные серверы, сохраняются в общем credentials provider Harness. Сессии одного профиля не ищут токены в рабочих папках. Настройки позволяют сохранить несколько ключей и привязать workspace или папку к нужному подключению. Секреты не возвращаются в интерфейс и не принимаются инструментами агента.

Выбор: самая вложенная каноническая папка, затем workspace. Неоднозначное членство сессии в workspace, отсутствующее подключение или отсутствие привязки приводят к ошибке. Автоматического выбора первого ключа нет. Канонизация через realpath учитывает симлинки; отдельный worktree вне привязанного дерева требует своей привязки либо членства в том же workspace.

## Возможности

- Настройки → плагины → GitHub и GitLab: одна редактируемая таблица подключений с колонками «Название», «Тип», «Ключ» и «Воркспейсы». Ключ вводится скрытым полем; сохранённое значение не загружается обратно. Добавление и изменение выполняются в строке, workspace выбираются флажками в последней колонке; адрес собственного сервера свёрнут в колонке типа. Отдельных форм подключений и привязок нет. Существующие привязки папок сохраняются в backend, но их редактор не выводится в упрощённой таблице. Сохранение ключа и изменение нескольких привязок — последовательные операции, не общая транзакция: при сбое нужно обновить таблицу и проверить частичный результат.
- `forge_connection`: показывает выбранное подключение без токена.
- `forge_request`: REST API issues, PR/MR, CI и исходников выбранного репозитория. GitHub: `repos/OWNER/REPO/issues`; GitLab: `projects/GROUP%2FREPO/merge_requests`. Ответы внешние и недоверенные; списки ограничены одной страницей, используйте API-параметры пагинации.
- Любая запись требует разового approval Harness, в том числе при полном файловом доступе. После неизвестного результата запись нельзя автоматически повторять: сначала проверьте сервис.

## Безопасность и ограничения

Хранение — один grant record `workain-forge/configuration`. Токены, метаданные и привязки изменяются атомарно через `modifyRecord`; параллельные сессии не перетирают разные поля вне этой операции. Используется существующее хранилище credentials, не отдельные файлы по workspace. Локальный credentials provider хранит значения открытым текстом с файловыми правами владельца, а не в зашифрованном OS keychain. Плагин не защищает от других доверенных плагинов или неограниченного shell того же пользователя.

Только HTTPS, без передачи авторизации по redirect. Адрес API выводится из сохранённого хоста: GitHub.com → api.github.com, GitHub Enterprise → `/api/v3`, GitLab → `/api/v4`. Самоподписанные сертификаты и GitLab под URL-префиксом пока не поддерживаются. Используйте минимальные scopes и ограничение доступа к репозиториям на стороне сервиса.

Управление подключениями доступно только через owner-only `connection.fetch` route Harness. Токен не попадает в аргументы инструментов и логи переписки; UI не использует localStorage для токенов. Настройки не являются ACL репозиториев: доступ определяют права сохранённого ключа. Привязка выбирает ключ, но не запрещает сессии запрашивать другой репозиторий, доступный тому же ключу.

Пока нет интеграции Git clone/fetch/push с credential helper. Официальная forge-панель тоже не использует эти ключи: её общий cache адресован host/repository/PR, не подключением, поэтому простая подмена токена раскрыла бы данные между аккаунтами. Безопасный мост требует отдельной доработки ключей cache и provider API; визуализация необязательна и отложена.

## Сборка и проверка

Для тестов в checkout форка сначала выполните `pnpm install --frozen-lockfile` из корня: тест Loader использует тестовую инфраструктуру и credentials-local монорепозитория. Затем из этой папки:

```sh
npm install --ignore-scripts --workspaces=false
npm test
npm run build
```

Поля Cordis config: `timeoutMs` (по умолчанию 30000) и `maxBodyBytes` (1048576); оба — положительные целые не больше 2147483647. При неверных значениях плагин не загружается. Запрос настроек ограничен дополнительно 64 КиБ.

Установка через plugin manager поддерживаемого DSH 0.2.2-rc.1 из собранного пакета. Не заменять всю работающую установку Harness этим checkout: форк имеет независимые изменения. После установки frontend-плагина обновить текущую страницу и проверить фактическое появление настроек. Bundle не включён в defaults.

## Model experience

Два инструмента добавляют схемы в контекст подключённых сессий. Ответ `forge_connection` содержит только публичные метаданные. `forge_request` возвращает JSON внешнего сервиса и не добавляет системных инструкций. Значения токенов не должны попадать в model context или журнал сессии. Отдельной фоновой индексации и polling нет.
